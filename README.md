# Admin Package

Admin dashboard for the online store.

## Environment Variables

⚠️ **Do not create a `.env.local` file in this directory!**

All environment variables are managed from the **root `.env` file**.

Edit: `/Users/oleksandrprokopenko/projects/online-store/.env`

The `.env.local` file in this directory is auto-generated by running `npm run env:sync` from the root.

**Important:** Admin variables must have the `VITE_` prefix to be exposed to the frontend.

See [Shared Environment Variables Guide](../../docs/SHARED_ENV_GUIDE.md) for details.

## Development

From the root of the monorepo:

```bash
npm run dev:admin
```

Or from this directory:

```bash
npm run dev
```

## Building

From the root:

```bash
npm run build:admin
```
